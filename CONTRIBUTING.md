# Contributing to NOVA

Thank you for your interest in improving NOVA.

## Getting started

1. Fork the repository.
2. Create a focused feature or documentation branch.
3. Make and test your changes locally.
4. Open a pull request with a clear description.

## Pull requests

Please keep pull requests focused and explain what changed, why it changed, and how it was tested.

## Security

Never commit API keys, passwords, `.env` files, or other secrets.
