pyttsx3 was not installed in the environment

voice_ai.py imported pyttsx3 but the active environment did not contain it. Solution: activate the project venv and run python -m pip install pyttsx3, then verify with python -c "import pyttsx3; print("TTS OK")". Packaging note: PyInstaller may need the package and its runtime dependencies collected into the final build.
